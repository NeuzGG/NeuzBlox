How it works

Three moving parts, none of them a hack.

Nothing is patched, no memory is read or written, no code is injected into Roblox, and no gameplay is automated. NeuzBlox starts clients and arranges windows.

1

Hold the lock Roblox checks

On startup the client claims a named Windows kernel object. A second copy finds it already taken, hands off to the first client and quits — that is the whole reason you only get one window. NeuzBlox claims it first and keeps it, so every client that follows just keeps running. 

new Mutex(false, "ROBLOX_singletonMutex", out createdNew);
// held on a dedicated thread for the app's lifetime —
// mutex ownership dies with the thread that took it
2

Mint one launch ticket per account

When you press Play on the website, Roblox issues a single-use authentication ticket for your session. NeuzBlox asks for exactly the same thing, once per saved account — which is what puts a different login in each window instead of three copies of one. 

POST https://auth.roblox.com/v1/authentication-ticket
→ rbx-authentication-ticket: <single-use ticket>
3

Hand the ticket to a fresh client

The ticket goes to the client in the same launch URI your browser would send. NeuzBlox asks Roblox which build is current first — launching any other one makes the client bounce through its own installer, which then opens a window you never authenticated. 

roblox-player:1+launchmode:play
  +gameinfo:<ticket>
  +placelauncherurl:<url-encoded PlaceLauncher>
  +browsertrackerid:<id>+robloxLocale:en_us

What you get

Built for running four clients without losing track of them.

Accounts

Saved sessions, encrypted

Unlimited accounts with their own alias, note and avatar. Sessions are sealed with Windows DPAPI under your user — another Windows account on the same PC cannot read them, and the file is useless on another machine.

Launching

One click, staggered

Launch one, the ticked ones, or everything. Clients start a few seconds apart and one at a time, because Roblox rate-limits rapid logins and two simultaneous updaters abort each other.

Destinations

Anywhere you can join

The Roblox home app, a place link or ID, a private server link, a specific server by job ID, or follow a friend into their game. Save any of them as a preset.

Windows

Tiled and labelled

Every client's title bar gets renamed to its account, so you can tell them apart on the taskbar. One click tiles them all — grid, columns, rows or cascade.

Instances

Live state, not guesswork

Queued → authenticating → starting → running → closed, with PID and uptime for each. If Roblox is mid-update it says so with a clock, and retries once on its own instead of dying quietly.

Build

One file, no runtime

A single 252 KB executable. No installer, no admin rights, no NuGet packages — it compiles with the C# compiler already inside Windows. The JSON parser, dark theme and animation engine are all hand-written.

Rich presence

Your friends see the game, not a generic status.

When every client is in the same game, the big tile is that game's own Roblox art and the text is its name. Mixed games, the home app, or nothing running fall back to the NeuzBlox mark.

It talks to your Discord client over its local pipe — no library, no account linking, nothing leaves the machine. Tick one box and it works; the application ID ships inside the app, so there is nothing to paste.

Straight answers

What it does not do.

Not an exploit

  • No files patched, no memory read or written
  • No code injected into the Roblox process
  • No gameplay automated, no inputs sent
  • Nothing hidden from Roblox — it launches clients the same way the website does
  • Nothing uploaded anywhere except roblox.com

Treat a cookie like a password

  • A .ROBLOSECURITY value is a full login — no password prompt, no 2FA
  • Only ever paste one you copied yourself, from your own browser
  • Never paste one into a site or tool you do not trust
  • "Log out of all sessions" on roblox.com kills every saved cookie instantly — that is your kill switch
  • Alt accounts are allowed by Roblox; how you use them is between you and their Terms
